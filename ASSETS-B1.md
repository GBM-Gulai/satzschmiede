# Satzschmiede – B1 art list 🎨 (today's Vienna)

Everything the new level **B1 "Der Job"** still needs – **35 images**. Until an image exists, the game shows an emoji, so you can make them in any order.
The ☐ column is for ticking off what you've done.

## How to make them

1. Open Gemini and start a **new chat** for B1.
2. Send the **style message** below first, then the prompts one at a time.
3. If an image drifts in style: *"Same style as before, please – painterly storybook, warm light, modern Vienna."*
4. Save as **JPG** with the **exact lowercase file name** in the folder shown (Gemini's long names are fine too – tell me and I'll rename them).
5. Squares (1:1) for characters, enemies and encounters · tall 9:16 for backgrounds · tall 2:3 for card frames.

## Style message (send this first)

> I'm making a card game called "Satzschmiede" about a newcomer learning German in Vienna. Please create ALL images as **hand-painted storybook illustrations – never photos, never photorealistic, never 3D renders**. Style: whimsical European children's-book painting, visible soft brush strokes, gentle paper grain, warm muted palette of deep teal, moss green, amber and burnt orange, slightly exaggerated cartoon proportions, cosy and a little magical and humorous. This chapter is set in **today's Vienna** (job centre, office, presentations) – modern things like screens, phones and office furniture are painted in the same storybook way, and the monsters are everyday office things that have come alive. Characters are centred, shown from the waist or chest up, with a simple softly blurred background. No text, no letters, no logos, no frames, no watermarks. Reply "ready" and then I'll send the images one by one.

**If an image still comes out realistic**, reply: *"Please redo it as a hand-painted storybook illustration with visible brush strokes, like a children's book – not realistic, not a photo."*
